Connect to the osu! API

ppfarmer needs its own API client, every user can create one. You will only need to do this once.

  1. Open your osu! account settings and scroll to OAuth.
  2. Click New OAuth Application, give it any name, leave the callback URL empty, then Register application.
  3. Copy the Client ID and the Client Secret below.

Stored locally. Do not share these with anyone. It's yours only.
